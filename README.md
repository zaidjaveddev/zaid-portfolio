# Zaid Javed — Portfolio

Personal portfolio website for Zaid Javed, a BS Information Technology student and aspiring Frontend Web Developer.

## Tech Stack
- React
- Vite
- JavaScript
- CSS3
- Lucide React

## Sections

## Projects
Medical Dashboard, Admin Dashboard, and SmartDoc (planned FYP project).
